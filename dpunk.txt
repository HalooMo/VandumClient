--------------------------------------------------------------------------------
1. ЧТО ТАКОЕ DPUNK
--------------------------------------------------------------------------------

Dpunk — веб-сервис быстрого закадрового AI-дубляжа.

Пользователь загружает видео/аудио (или даёт ссылку, например YouTube),
выбирает языки и настройки голоса — получает готовый MP4 с переводом и
озвучкой. Акцент продукта: скорость и простота, а не студийная
«кино-идеальность».

Типичный сценарий:
  1) Регистрация / вход (email или Google)
  2) Создание проекта (мастер из нескольких шагов)
  3) Ожидание обработки (очередь на GPU-сервере)
  4) Просмотр в плеере и скачивание MP4

Целевая аудитория:
  - авторы YouTube / Shorts / Reels
  - образовательные курсы и лекции
  - подкасты → видео
  - внутренние корпоративные ролики
  - черновики локализации до дорогой студии


--------------------------------------------------------------------------------
2. ЧЕМ DPUNK НЕ ЯВЛЯЕТСЯ
--------------------------------------------------------------------------------

  - Не синхронизация губ (lip-sync) — это закадр
  - Не замена актёрской озвучки для кинопремьер
  - Не «магическое» идеальное качество только по текстовому промпту
    (VoiceDesign по промпту может звучать слабо; лучше клон/cast)


--------------------------------------------------------------------------------
3. АРХИТЕКТУРА (ДВА СЕРВЕРА)
--------------------------------------------------------------------------------

Dpunk состоит из двух логических частей:

  A) Клиент (этот репозиторий, домен dpunk.online)
     - Flask-сайт: UI, аккаунты, проекты, API-ключи пользователей
     - Своя БД (PostgreSQL / SQLite): users, projects, quotas, api_keys
     - Проксирует задачи на SpeechLab
     - Опционально скачивает медиа по URL через yt-dlp

  B) Бэкенд SpeechLab (отдельный inference-сервер, GPU)
     - Принимает файл + параметры дубляжа
     - ASR → перевод → TTS / клон / cast → сборка MP4
     - Одна активная тяжёлая задача на GPU (очередь)

Клиент НЕ шарит БД с SpeechLab. Связь только по HTTP API
(SPEECHLAB_BASE_URL + серверный SPEECHLAB_API_KEY).

Если SpeechLab недоступен — сайт может открываться, но дубляж не работает.


--------------------------------------------------------------------------------
4. ВОЗМОЖНОСТИ ПРОДУКТА (ТЕКУЩИЙ ФУНКЦИОНАЛ)
--------------------------------------------------------------------------------

Аккаунты и доступ:
  - Регистрация / вход по email + подтверждение почты
  - Google OAuth
  - Админ-панель пользователей
  - Дашборд аналитики (для админа)

Создание дубляжа (веб-мастер):
  - Загрузка файла (MP4, MKV, MOV, AVI, WebM, WAV, MP3, M4A)
  - Или ссылка (YouTube и др.) через yt-dlp
  - Лимит размера файла (по умолчанию до ~150 МБ)
  - Языки source / target (в т.ч. auto для source)
  - VoiceDesign: пол, возраст, текстовый промпт, температура TTS
  - Громкость дубляжа и доля оригинала в миксе
  - Встроенные cast-голоса (Локи / Том Харди / Тор; режим speakers)
  - Клонирование из своих сэмплов (male/female, возрастные группы)
  - Статус задачи, превью в Plyr, скачивание MP4
  - Перезапуск проекта с новыми настройками

Публичное API (ключи dpk_… у пользователя):
  - POST /api/v1/dub
  - GET  /api/v1/jobs, /jobs/<id>, /download
  - GET  /api/v1/cast-voices
  - Документация на сайте

Ограничения (технические, уже в коде):
  - Дневная квота запусков на пользователя (MAX_DUB_JOBS_PER_DAY, по умолч. 20)
  - Rate limit на API dub
  - На upstream обычно одна GPU-задача одновременно


--------------------------------------------------------------------------------
5. ЦЕННОСТНОЕ ПРЕДЛОЖЕНИЕ
--------------------------------------------------------------------------------

Для автора контента:
  «За час, а не за неделю и не за студийный бюджет — ролик на другом языке.»

Для разработчика / интеграции:
  «Тот же пайплайн через API-ключ, без ручного UI.»

Дифференциация:
  - быстрый заказной закадр, а не долгий монтаж
  - мультиспикер / cast / клон в одном мастере
  - веб + API из одного кабинета


--------------------------------------------------------------------------------
6. ПОДПИСОЧНАЯ БИЗНЕС-МОДЕЛЬ
--------------------------------------------------------------------------------

Модель: Freemium + ежемесячная / годовая подписка (SaaS) + опционально
пакеты API для интеграторов.

Деньги берутся не «за клик наугад», а за:
  - число запусков дубляжа в месяц (credits / jobs)
  - лимит минут исходного медиа в месяц (fair use GPU)
  - лимит размера файла / длительности одного ролика
  - число API-ключей и rate limit
  - приоритет в очереди GPU

Учёт (рекомендуемая логика продукта):
  1 credit = 1 успешный/запущенный dub (как сейчас dub_usage),
  дополнительно списание минут по длительности исходника
  (чтобы длинные ролики не убивали экономику на «1 job»).


--------------------------------------------------------------------------------
6.1. ТАРИФЫ (ПРЕДЛОЖЕНИЕ К ЗАПУСКУ)
--------------------------------------------------------------------------------

Цены ориентировочные в RUB; финальные — под себестоимость GPU и маркетинг.
1 «кредит» ≈ 1 запуск дубляжа; минуты — сумма длительности исходных роликов.

┌──────────────┬─────────────┬──────────────┬──────────────┬────────────────┐
│              │ Free        │ Creator      │ Pro          │ Business       │
├──────────────┼─────────────┼──────────────┼──────────────┼────────────────┤
│ Цена / мес   │ 0 ₽         │ 990 ₽        │ 2 990 ₽      │ 9 990 ₽        │
│ Год (−20%)   │ —           │ 9 500 ₽/год  │ 28 700 ₽/год │ 95 900 ₽/год   │
├──────────────┼─────────────┼──────────────┼──────────────┼────────────────┤
│ Кредиты/мес  │ 3           │ 30           │ 100          │ 400            │
│ Минуты/мес   │ 15 мин      │ 120 мин      │ 500 мин      │ 2 000 мин      │
│ Макс. файл   │ 50 МБ       │ 150 МБ       │ 150 МБ       │ 300 МБ*        │
│ Макс. длина  │ 5 мин       │ 20 мин       │ 45 мин       │ 90 мин         │
│ Очередь      │ обычная     │ обычная      │ приоритет    │ высший         │
│ Cast / клон  │ да          │ да           │ да           │ да             │
│ API-ключи    │ нет         │ 1 ключ       │ 3 ключа      │ 10 ключей      │
│ API rate     │ —           │ 10/час       │ 30/час       │ 100/час        │
│ Вотермарк**  │ опционально │ нет          │ нет          │ нет            │
│ Поддержка    │ FAQ         │ email        │ приоритет    │ менеджер       │
└──────────────┴─────────────┴──────────────┴──────────────┴────────────────┘

* 300 МБ — при согласовании с лимитом SpeechLab.
** Вотермарк на Free — инструмент конверсии в платный тариф (решение продукта).

Дополнительно (не подписка):
  - Пакет «+50 кредитов» разово (например 1 490 ₽) — для пиков без апгрейда плана
  - Enterprise: свой SLA, выделенная очередь GPU, счёт, кастомные cast — по договору


--------------------------------------------------------------------------------
6.2. ЧТО ОГРАНИЧИВАЕТ FREE
--------------------------------------------------------------------------------

Цель Free — дать попробовать качество и UX, но не дать «сидеть» на GPU бесплатно.

  - Мало кредитов и минут
  - Меньший лимит файла / длины
  - Без API (или только sandbox с жёстким лимитом)
  - Обычная (медленная) очередь при загрузке GPU
  - Опционально лёгкий вотермарк / брендинг Dpunk в углу

Конверсия: после 2–3 удачных роликов автор упирается в лимит → Creator.


--------------------------------------------------------------------------------
6.3. МЕТРИКИ UNIT-ECONOMICS (КАК СЧИТАТЬ)
--------------------------------------------------------------------------------

Себестоимость одного ролика примерно:
  GPU-время × цена GPU-часа
  + трафик/диск
  + доля SpeechLab/инфры
  + поддержка

Нужно держать:
  ARPU (средний чек) > COGS на активного платящего × запас 2–3×

Пример контроля:
  - Creator 990 ₽ / 30 jobs → ~33 ₽ за job «потолок» выручки
  - Если средний ролик жрёт GPU на 80–150 ₽ — тариф убыточен →
    резать минуты, поднимать цену или вводить списание по минутам.

Поэтому в модели заложены И кредиты, И минуты.

6.4. ОПЛАТА И БИЛЛИНГ (К РЕАЛИЗАЦИИ)

--------------------------------------------------------------------------------
7. GO-TO-MARKET (КРАТКО)
--------------------------------------------------------------------------------

  1) Контент: «до/после» дубляжа на Shorts / Telegram
  2) Free без карты → быстрый wow на коротком ролике
  3) Creator как основной mass-market чек
  4) Pro / Business через API-доки и интеграторов
  5) Партнёрки с агентствами локализации (черновик у Dpunk, финал у студии)


--------------------------------------------------------------------------------
8. РИСКИ И ОГРАНИЧЕНИЯ МОДЕЛИ
--------------------------------------------------------------------------------

  - GPU — главный bottleneck и COGS; одна очередь = ожидание в пике
  - Качество TTS/VoiceDesign влияет на churn
  - ToS площадок (YouTube download) — ответственность пользователя
  - Зависимость от доступности SpeechLab (второй сервер)
  - Abuse free-тарифа → нужны device/fingerprint + жёсткие лимиты


--------------------------------------------------------------------------------
9. ИТОГ
--------------------------------------------------------------------------------

Dpunk — SaaS-обёртка вокруг GPU-пайплайна закадрового дубляжа:
веб-кабинет + API, скорость важнее студийного глянца.

Бизнес-модель: freemium → месячная/годовая подписка (кредиты + минуты +
очередь + API), разовые top-up пакеты, Enterprise по договору.

Технический деплой клиента: см. DEPLOY.md и README.md.
Спецификация upstream API: см. for_client.txt и /docs на сайте.
